# Project Context

Project Name

Decision Intelligence Platform (DIP)

Slogan

Make better decisions through data, analytics and AI.

## Product Vision

DIP is a generic Decision Intelligence Platform.

Travel Intelligence is the first supported domain.

The platform consolidates information from multiple providers and produces explainable recommendations based on business rules, analytics and Artificial Intelligence.

## Architectural Principles

- Clean Architecture
- Domain Driven Design
- SOLID
- API First
- Provider Pattern
- Strategy Pattern
- Modular Monolith
- Cloud Ready

## MVP Principles

Prefer simplicity.

Avoid overengineering.

Every architectural decision must preserve future extensibility.
