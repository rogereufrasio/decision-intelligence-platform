# Coding Standards

General Principles

- Keep implementations simple.
- Prefer readability.
- Avoid unnecessary abstractions.
- Follow SOLID.
- Use descriptive names.
- Keep modules cohesive.

Architecture

- Business rules cannot depend on infrastructure.
- Providers communicate through interfaces.
- APIs expose canonical models.

Code Quality

- Small functions.
- Low coupling.
- High cohesion.
- No duplicated logic.

Documentation

Every relevant architectural decision must update ADR documentation.

Every product evolution must update DIP documentation.
