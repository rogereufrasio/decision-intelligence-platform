# Review Checklist

Before considering a task complete, verify:

## Architecture

- Clean Architecture respected.
- Layer boundaries preserved.
- Providers isolated.

## Product

- Acceptance criteria satisfied.

## Engineering

- No duplicated logic.
- Clear naming.
- Small functions.
- Readable code.

## Tests

- Unit tests implemented.

## Documentation

- ADR updated if necessary.
- DIP updated if necessary.

## Git

- Conventional Commit.
