# Overview

This directory contains the complete documentation for the **Decision Intelligence Platform (DIP)**.

The documentation follows a structured approach inspired by modern Product Management, Enterprise Architecture and Software Engineering practices. Each document has a single responsibility and contributes to the overall understanding of the product, from business vision to implementation.

The documentation is intended to support the complete product lifecycle, including discovery, design, architecture, implementation and future evolution.

# Contribution Guidelines

Every significant product or architectural decision should be documented before implementation.

Whenever applicable:

- Update the corresponding documentation.
- Record architectural decisions using ADRs.
- Keep documentation synchronized with the implementation.
- Prefer evolving existing documents over creating duplicates.
