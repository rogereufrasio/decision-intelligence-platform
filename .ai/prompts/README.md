# AI Prompts

This directory contains reusable prompts used throughout the Decision Intelligence Platform development lifecycle.

The objective is to standardize interactions with AI coding assistants.

Each prompt represents an engineering workflow rather than a one-time instruction.

Prompts are organized by development stage.

bootstrap/

Environment creation.

backend/

Backend implementation.

frontend/

Frontend implementation.

features/

Feature development.

reviews/

Architecture and code reviews.

Templates should be reused whenever possible.
