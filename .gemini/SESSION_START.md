# Session Start

At the beginning of every development session:

1. Read AGENTS.md.
2. Review Architecture Decision Records.
3. Review Product Documentation.
4. Review AI Context.
5. Review AI Rules.
6. Review this Gemini configuration.

When information conflicts, the priority is:

1. AGENTS.md
2. ADRs
3. DIPs
4. .ai
5. .gemini

Never violate documented architectural decisions.

When uncertain, ask for clarification instead of making assumptions.
